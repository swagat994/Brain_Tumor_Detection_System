# Brain Tumor Detection System

A deep learning-based web application for brain MRI analysis that classifies scans into Glioma, Meningioma, Pituitary Tumor, and No Tumor categories. The system also generates Grad-CAM visualizations to improve prediction interpretability.

## Features

* Brain tumor classification using EfficientNetB0
* Multi-class prediction (Glioma, Meningioma, Pituitary, No Tumor)
* Grad-CAM heatmap generation
* FastAPI backend for inference
* Streamlit frontend for user interaction
* Real-time prediction with confidence scores

## Tech Stack

* Python
* TensorFlow / Keras
* FastAPI
* Streamlit
* OpenCV
* NumPy
